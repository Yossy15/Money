# Yossy Money Manager — Web Edition

แอปบริหารเงินส่วนตัวแบบ HTML, CSS และ JavaScript ไม่ใช้ Backend และไม่ต้องติดตั้ง Framework

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. เลือกเดือนเพื่อดูข้อมูลของเดือนนั้น

## จัดการ JSON
- กด **อ่าน JSON** เพื่อเลือกไฟล์ `.json` ที่มี `station_cu` และ `Stations`
- แก้ไขเงินเดือน, OT, เงินออม และรายการรายจ่ายได้ในหน้าเว็บ
- กด **บันทึก JSON** เพื่อดาวน์โหลดข้อมูลฉบับล่าสุด
- ตัวอย่างข้อมูลเริ่มต้นอยู่ที่ `data/yossy_money_manager.json`

## โครงสร้าง
- `station_cu`: key ของเดือนที่กำลังเลือก
- `Stations`: ข้อมูลของแต่ละเดือน
- `Money`: เงินเดือน, OT และรายรับอื่น
- `Expenses`: รายการรายจ่าย
- `Savings`: เงินออม

## ข้อควรทราบ
JSON เป็นไฟล์ข้อมูลหลัก การแก้ไขในหน้าเว็บจะอยู่ในหน่วยความจำของแท็บจนกว่าจะกด **บันทึก JSON** เพื่อดาวน์โหลดไฟล์ใหม่ หากปิดหน้าเว็บก่อนดาวน์โหลด การแก้ไขที่ยังไม่ได้ส่งออกอาจสูญหาย

เปิด `index.html` ผ่าน file:// ได้โดยตรง ไม่จำเป็นต้องใช้ server.
